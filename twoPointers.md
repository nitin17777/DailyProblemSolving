# Two Pointers

## What is it?
A technique where two pointers are used to traverse an array, often from opposite ends.

## When to Use
- Sorted arrays
- Pair or triplet problems
- Sliding window problems

## Example Use Cases
- Find pair with given sum
- Remove duplicates

## Common Mistakes
- Moving both pointers incorrectly
- Not handling edge cases

## Related Concepts
- Sliding Window
- Binary Search
