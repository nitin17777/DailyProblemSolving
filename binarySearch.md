# Binary Search

## What is it?
Binary Search is an algorithm used to find an element in a sorted array by repeatedly dividing the search space in half.

## Time Complexity
- Best Case: O(1)
- Average/Worst Case: O(log n)

## When to Use
- Array is sorted
- Need fast searching

## Steps
1. Find mid index
2. Compare target with mid
3. Move left or right accordingly

## Common Mistakes
- Incorrect mid calculation
- Infinite loop due to wrong boundaries

## Related Concepts
- Divide and Conquer
